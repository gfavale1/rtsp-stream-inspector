# Documentation Assets

This directory is reserved for screenshots and other documentation-only assets.

Recommended screenshot filenames:

- `ui-dashboard.png` — connection/triage dashboard with sanitized endpoint information.
- `ui-h264.png` — H.264 inspection panel.
- `ui-quality.png` — quality metrics panel.
- `ui-reports.png` — report manager panel.

Screenshots must not show:

- real RTSP URLs;
- usernames;
- passwords;
- Authorization headers;
- private camera IPs;
- Basic Auth tokens;
- private network topology details.

Use sanitized local streams or documentation-safe placeholders before capturing screenshots.
